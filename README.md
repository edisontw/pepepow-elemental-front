# PEPEPOW Elemental Front｜元素戰線

A deterministic 2.5D browser RTS roguelite built with TypeScript, PlayCanvas, and Vite.

## Development

```bash
npm install
npm run dev
```

Required verification:

```bash
npm run test
npm run build
```

M00 establishes only the permanent repository, renderer, RTS camera, fixed-tick simulation, deterministic RNG, debug overlay, tests/CI, and manifest conventions. Procedural terrain and combat begin in later milestones.

Canonical project specifications are in `docs/`.
